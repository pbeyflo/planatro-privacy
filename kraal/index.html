reparto de secciones

Los vetos y las afinidades son mutuos: si marcas que Ana no trabaja con Luis, Luis queda marcado con Ana.

Añadir varias personas de una vez

El mínimo y el máximo son objetivos, no muros: si no cuadran, el reparto se hace igual y el aviso lo dice.

Todo se guarda solo en este navegador (localStorage). Exporta el JSON para tener copia o para llevarte el trabajo a otro ordenador. Las puntuaciones que usa el reparto: 1ª opción 100, 2ª 60, 3ª 30, cada afinidad cumplida +25, cada veto roto −1000, cada plaza por debajo del mínimo −300 y cada una por encima del máximo −500.
