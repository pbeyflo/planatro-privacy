# Política de privacidad de Planatro

Página estática con la política de privacidad de la app Android de Planatro,
servida por GitHub Pages desde la raíz de `main`. Es la URL que se indica en
Play Console.

- `index.html`: la política.
- `PUBLICAR.sh`: crea el repo, sube el contenido y activa GitHub Pages. Solo
  hace falta la primera vez; después basta con commitear y hacer push.
